Этап 1. Разминка: переменные, числа, math
Задача
Напишите три функции для базовой статистики каталога.
Функция average_rating(movies) возвращает среднюю оценку по каталогу, округленную до одного знака (round).
Функция catalog_age_stats(movies, current_year=2026) возвращает кортеж (самый старый фильм в годах, самый новый фильм в годах, среднее), где среднее округлено вверх до целого с помощью math.ceil.
Функция duration_in_hours(minutes) переводит минуты в формат "2ч 35м", используя целочисленное деление и остаток от деления.
Требования
Использовать модуль math там, где это уместно (math.ceil).
round() и целочисленное деление/остаток от деления (// и %) применить по назначению.
Результат catalog_age_stats — неизменяемая запись, то есть tuple, а не список.
Подсказка
Возраст фильма — это current_year минус год выпуска. Для перевода минут в часы удобно взять частное от деления на 60 как часы, а остаток — как минуты.
Этап 2. Условия и match
Задача
Напишите функцию rating_tier(rating), которая по оценке возвращает категорию: "шедевр" (≥9), "хорошо" (7–8.9), "средне" (5–6.9), "слабо" (<5). Реализуйте ее через if/elif, а внутри используйте тернарный оператор хотя бы один раз.
Напишите функцию decade_label(year), которая через оператор match возвращает метку "новые" (после 2020), "недавние" (2015–2020) или "старые" (раньше 2015).
Требования
rating_tier обязательно содержит хотя бы один тернарный оператор.
decade_label обязательно реализована через match с использованием case _ if ... для сопоставления диапазонов.
Границы диапазонов не должны пересекаться и не должны терять пограничные значения.
Подсказка
match умеет сопоставлять не только точные значения, но и произвольные условия через case _ if <условие>: — это как раз то, что нужно для диапазонов лет.
Этап 3. Циклы
Задача
Продемонстрируйте работу с for, while и управляющими конструкциями циклов на каталоге.
С помощью for и continue выведите на экран (print) названия всех фильмов, которые НЕ относятся к жанру "comedy".
С помощью while и break найдите первый по порядку в списке фильм с рейтингом выше 9.0; если такого фильма нет, цикл должен завершиться веткой else с сообщением "Шедевров не найдено".
Напишите функцию count_long_movies(movies, threshold=120), которая через for с накопительной переменной считает количество фильмов длиннее threshold минут.
Требования
Обязательно использовать continue в первом пункте и break — во втором.
Ветка else цикла while должна быть по-настоящему задействована (проверьте и случай, когда шедевров нет).
В count_long_movies нельзя использовать sum() по списку-фильтру — только накопление в цикле.
Подсказка
else у цикла while выполняется, если цикл закончился естественным образом, без break, — удобный способ отличить «не нашли» от «нашли и прервались».
Этап 4. Строки
Задача
Напишите функцию normalize_title(title), которая приводит строку к формату Title Case (каждое слово с заглавной буквы) без использования str.title() напрямую: разбейте строку по пробелам и соберите заново вручную, меняя первую букву каждого слова через срез (word[0].upper() + word[1:]).
Напишите функцию make_slug(title), которая превращает нормализованное название в «слаг» вида the-quiet-algorithm.
Напишите функцию format_report_line(movie), возвращающую единую строку с описанием фильма.
Пример результата

normalize_title("silent hours")      # "Silent Hours"
make_slug("Silent Hours")            # "silent-hours"
format_report_line(movies[7])
# '"The Quiet Algorithm" (2024) — 9.2/10, 1ч 58м, жанры: drama, sci-fi' 
Требования
normalize_title нельзя реализовывать через str.title().
make_slug использует .lower() и .replace().
format_report_line обязательно собирается через f-строку и вызывает duration_in_hours из этапа 1.
Жанры в строке отчета отсортированы по алфавиту.
Подсказка
Срез word[1:] — это «все, кроме первого символа»; вместе с word[0].upper() он и дает смену регистра первой буквы вручную.
Этап 5. Списки
Задача
Напишите функцию titles_sorted_by_rating(movies), возвращающую список названий фильмов, отсортированных по убыванию рейтинга.
Напишите функцию top_n_by_rating(movies, n=3), возвращающую список из n кортежей (title, rating) — топ по рейтингу.
Пример результата

top_n_by_rating(movies, 3)
# [("The Quiet Algorithm", 9.2), ("midnight in oslo", 8.9), ("The Dune Chronicles", 8.6)] 
Требования
Сортировку выполнять через sorted() с параметром key, а не вручную через циклы сравнения.
Каждая запись в top_n_by_rating — именно tuple, а не список.
titles_sorted_by_rating не должна изменять исходный список movies.
Подсказка
key принимает функцию, которая возвращает значение для сравнения элементов; для сортировки по убыванию пригодится параметр reverse=True.
Этап 6. Словари
Задача
Напишите функцию count_by_genre(movies), возвращающую словарь {жанр: количество фильмов}, построенный вручную через цикл и метод dict.get() (без Counter).
Напишите функцию actor_filmography(movies), возвращающую словарь {актер: [список названий фильмов]}.
С помощью генератора словаря (dict comprehension) постройте словарь {title: rating} только для фильмов с рейтингом выше среднего (используйте average_rating из этапа 1).
Пример результата

count_by_genre(movies)
# {"drama": 5, "sci-fi": 3, "comedy": 3, "thriller": 3, "action": 2, "mystery": 1} 
Требования
count_by_genre не использует collections.Counter.
Значение по несуществующему ключу получать через dict.get() со значением по умолчанию.
Словарь {title: rating} обязательно построен генератором словаря, а не циклом с присваиванием.
Подсказка
dict.get(key, 0) возвращает 0, если ключа еще нет в словаре, — это избавляет от проверки «если ключ уже есть» перед каждым увеличением счетчика.
Этап 7. Множества
Задача
Напишите функцию all_genres(movies), возвращающую множество всех уникальных жанров каталога.
Напишите функцию common_actors(movie1, movie2), возвращающую множество актеров, снимавшихся в обоих фильмах.
Напишите функцию genres_only_in_one(movies_a, movies_b), которая возвращает жанры, встречающиеся в movies_a, но не встречающиеся в movies_b.
Пример результата

common_actors(movies[0], movies[3])          # {"O. Isaac"}
genres_only_in_one(movies[5:6], movies[:5])  # {"mystery"} 
Требования
all_genres строится через объединение множеств (| или .update()).
common_actors обязательно использует пересечение множеств (&).
genres_only_in_one обязательно использует разность множеств (-).
Подсказка
Множества хороши именно там, где важна уникальность и не важен порядок — объединение, пересечение и разность выполняются одной операцией без циклов.
Этап 8. Итераторы и генераторы
Задача
Напишите функцию-генератор iter_high_rated(movies, min_rating=8.0), которая через yield лениво отдает фильмы с рейтингом не ниже min_rating.
Продемонстрируйте ее работу циклом for с вызовом format_report_line.
Напишите генераторное выражение, которое считает суммарную длительность всех фильмов с рейтингом выше 7 в минутах, и передайте его в sum().
Пример результата

for movie in iter_high_rated(movies):
    print(format_report_line(movie))
# "The Dune Chronicles" (2021) — 8.6/10, 2ч 35м, жанры: drama, sci-fi
# "Midnight In Oslo" (2020) — 8.9/10, 2ч 4м, жанры: mystery, thriller
# "The Quiet Algorithm" (2024) — 9.2/10, 1ч 58м, жанры: drama, sci-fi

sum(m["duration_min"] for m in movies if m["rating"] > 7)   # 713 
Требования
iter_high_rated обязательно использует yield, а не возвращает готовый список.
Суммирование длительности обязательно через генераторное выражение внутри sum(), а не список в квадратных скобках.
min_rating должен оставаться параметром со значением по умолчанию.
Подсказка
Генератор не хранит все элементы в памяти сразу — он вычисляет следующий только тогда, когда его запросили, поэтому for movie in iter_high_rated(movies) работает так же, как обычный цикл по списку, но экономнее.
Этап 9. Итоговый отчет
Собираем все вместе.
Задача
Напишите функцию build_report(movies), которая объединяет результаты всех предыдущих этапов в единый консольный отчет: общую статистику, топ-3 фильма, количество фильмов по каждому жанру и полный список уникальных жанров каталога.
Пример отчета

ОТЧеТ ПО КАТАЛОГУ
Средний рейтинг: 7.2
Средний возраст фильмов: 8 лет

Топ-3 фильма:
  "The Quiet Algorithm" (2024) — 9.2/10, 1ч 58м, жанры: drama, sci-fi
  "Midnight In Oslo" (2020) — 8.9/10, 2ч 4м, жанры: mystery, thriller
  "The Dune Chronicles" (2021) — 8.6/10, 2ч 35м, жанры: drama, sci-fi

Фильмов по жанрам:
  drama — 5
  comedy — 3
  sci-fi — 3
  thriller — 3
  action — 2
  mystery — 1

Все жанры каталога: action, comedy, drama, mystery, sci-fi, thriller 
Требования
build_report — единственная точка входа: один ее вызов полностью воспроизводит отчет.
Жанры в списке количества отсортированы по убыванию числа фильмов.
Полный список жанров выводится одной строкой через ", ".join(...).
Подсказка
Строить build_report проще всего как последовательность вызовов уже готовых функций из предыдущих этапов — сама функция должна только вызывать их по очереди и печатать результат.
